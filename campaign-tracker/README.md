📊 Campaign Tracker — Dashboard de Campanhas e Métricas

Aplicação desenvolvida para gerenciamento e visualização de campanhas, focada em análise de métricas, organização de dados e experiência do usuário. O projeto foi construído utilizando React, TypeScript e consumo de APIs, com interface moderna, responsiva e suporte a Dark Mode.

✨ Funcionalidades:
• Dashboard com métricas dinâmicas
• Visualização de campanhas e vendas
• Gráficos interativos para análise de desempenho
• Integração com APIs
• Interface responsiva para diferentes dispositivos
• Dark Mode
• Componentização e organização escalável do código
• Tratamento de loading e estados da aplicação

🛠️ Tecnologias utilizadas:
React · TypeScript · JavaScript · Tailwind CSS · APIs REST · Vite · Git/GitHub

Durante o desenvolvimento, trabalhei bastante no refinamento da responsividade, estruturação dos componentes, correção de bugs e melhoria da experiência visual da aplicação, fortalecendo ainda mais minha prática com desenvolvimento frontend moderno.
